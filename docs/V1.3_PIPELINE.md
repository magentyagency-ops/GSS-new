## 1.4 État du bandeau dans le DOCX prod (HTTP réel)
- **Aucun fichier `word/header*.xml`** ; **161 `<w:sectPr>`** ; **0 `<w:headerReference>`**.
- Le bandeau n'est **pas** un en-tête Word : c'est un **dessin INLINE** = bande sombre + logo GSS
  (`image5.png`) **ancrés `behindDoc`** (position absolue page) + zones de titre `txbxContent`
  (texte clair `#F5F5DB` : « I. PRESENTATION », « 1. NOTRE CATALOGUE… »).
- Au rendu : sur les pages **de continuation** créées par le reflux de `cloneSpread`, la bande
  sombre + logo (ancrés à un paragraphe précis) **ne suivent pas** le texte → la zone de titre
  (texte clair) se retrouve **seule sur le fond gris** → bandeau « peu visible » (constat Stan).

## Hypothèse de cause racine
Le bandeau inline (élément flottant `behindDoc` ancré à un paragraphe) est **découplé du contenu**
quand `cloneSpread` insère des pages et fait refluer le texte. Le bandeau n'apparaît que sur la
1re page de chaque spread, pas sur les pages de continuation.

indépendamment du reflux → bandeau garanti sur chaque page.
